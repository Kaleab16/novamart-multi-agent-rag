# NovaMart Returns Policy

This is fictional policy content for the NovaMart learning project.

- Standard customers may request a return within 30 calendar days of delivery.
- Premium customers may request a return within 60 calendar days of delivery.
- The order must be marked as delivered before the normal return window begins.
- Eligibility is not confirmation that a refund has been issued.
- Items outside the normal window require support review; do not promise an exception.
- The support system must verify the order and customer tier before giving a decision.
